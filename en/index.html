The meaning of areel
areel /əˈriːl/

There is no clever acronym. AREEL is a record — twelve tracks by ariiol — and this domain is named after it.

I love this album. It is the kind of record that gives something back on every listen, and the name stayed with me long enough that I wanted it over the door. The flat grey, the single magenta sweep and the checkerboard on this page are all lifted from its cover.

All of that credit belongs to ariiol. The name is the best thing on this page and it was never mine — so if you have read this far, give the record the half hour it deserves. It is the better work.

HydrogenH₁

Self-hosted LLM proxy. The trick is Micro Agents — multi-stage pipelines any client calls as one model.

Live TypeScript MIT Self-hosted

The core — Micro Agents

One model name in.
Many model calls out.

A Micro Agent embeds a workflow inside a single model call. The client asks for one name and gets one answer back. Every stage in between is invisible to it, so nothing on the client side changes.

A stage can transcribe an image into text, and a model that cannot see answers anyway. That is only the obvious one — what the stages do is up to you. The limit is your imagination.

Inside one call

Client sends one model name + an image
one call in
Stage 1 — read a vision model transcribes it
text replaces the picture, inline
Stage 2 — answer a text-only model replies
one answer out
Client gets one ordinary response
In practice
01

Re-evaluate before response

Several models think it through together.

One model drafts, a second argues with it, and the draft comes back sharper. More than one mind on every answer — the client only ever sees the final one.

draft · strong model critique · another strong model critique says “APPROVED” → return draft → end else fall through ↓ revise · strong model → end

Costs one extra call. The second model can be shown your tools without being able to call them.

02

Pay by difficulty

A weak model picks the expensive one.

Stage 1 runs your cheapest model and does nothing but grade the request. Its verdict picks the path — hard work goes to the strong model, the rest falls through to the cheap one.

triage · cheap model output contains “HARD” → strong model → end else fall through ↓ answer · cheap model → end

Grading costs one cheap call. Branch on a regex instead and a router stage spends nothing at all.

FishBall鱼丸

Search agent for Android. The trick is refusing to guess — every claim traceable to a graded publisher, or no claim at all.

Live Kotlin MIT Android

The core — sourcing you can check

Every answer names
where it came from.

Each result is graded by who published it — a regulator, an edited institution, a named individual, or an anonymous post — before a word is written. The grade sits under the answer and changes its wording, so a claim resting on one forum thread never sounds like one resting on a health ministry.

When nothing above the bottom rung turns up, it says so rather than answering. An unsourced answer looks exactly like a good one minus a citation nobody notices is missing.

Inside one question

Thinking…
  • Searched — 9 results back
  • Read the drug regulator’s leaflet
  • Graded every publisher
  • Searching the other way now
  • Checking each quote against its page

Yes — the most common side effects are in the gut, and the drug regulator’s own leaflet lists nausea and heartburn first.

In practice
01

Quotes are cut, not written

The model points. The verifier cuts.

When a source's exact words appear, the model never types them. It selects a span, and that span is sliced out of the retrieved page and checked character by character before anyone sees it. No path through the code lets an invented quote reach the screen.

select · model names a span verify · sliced from the fetched page matches → quote shown → end else rejected ↓ retry · model told why → end

Costs nothing extra when the model quotes honestly, which is most of the time.

02

It argues with itself

A second search tries to prove the first wrong.

On anything that matters the app searches against what it just found. If the two sides disagree it shows both and says so. Silent agreement with the first page read is how a confident wrong answer gets made.

support · what the question asked disconfirm · the opposite claim they agree → answer plainly → end else fall through ↓ show both · name the disagreement → end

Costs one extra search round. It is why a health question takes twenty to forty seconds.

DSH-FishballV3

Always-on personal assistant for DeepSeek Harness. Coordinates your other DSH sessions over MCP + OAuth 2.1 without writing local files directly.

V3 Alpha DSH Monorepo MCP · OAuth 2.1 MIT

The core — one manager, one public seam

One session watches.
The rest do the work.

Fishball keeps one long-lived session that sits above your worker sessions. It gathers status, tracks tasks, relays or approves in-scope permission requests, questions, and plan reviews, and dispatches work on your behalf — while never editing local workspace files itself.

The two sides never import each other. A managed DSH exposes its sessions over standard MCP through dsh-connector, and Fishball talks to that endpoint like any other MCP client. Install one bundle for embedded mode, or run it standalone across machines.

$ dsh plugin --profile web add dsh-fishball-bundle@1.0.0-alpha.1

02 / DSH Plugins

Small tools for DSH

Three focused web plugins for DeepSeek Harness. Each fixes one everyday friction point in the workbench.

01 · Composer

dsh-smart-prompt

One-click ✦ prompt refinement right inside the DSH composer. Rewrites rough drafts into clean agent-ready instructions while preserving paths, code, URLs, and @mentions, with follow-up cards and instant revert.

JavaScript · MIT GitHub ↗
02 · Model Menu

dsh-model-quick-selector

Custom drag-to-reorder favorite model list and a Codex-style reasoning-effort slider built into the DSH model selector. Drag vertically to switch models, horizontally to adjust reasoning effort.

JavaScript · MIT GitHub ↗
03 · Workspace

dsh-better-workspace-file-manager

Upgrades the DSH Files tab with file uploads, streamed folder ZIP downloads, folder creation and deletion, drag-to-move, drag-to-chat (@path & images), and in-place text or Markdown editing.

JavaScript · MIT GitHub ↗
